## Projects

### [Elurance](https://elurance.com)
An AI workspace for slides, sheets and documents. Most AI tools only generate a file that you then download and fix in PowerPoint or Excel. Elurance puts the editor in the workspace, so what the AI makes is what you edit.

- Three full editors: slides, sheets and documents
- The assistant reads your live file and changes only what needs changing, instead of regenerating it
- PowerPoint, Excel and Word files import and export cleanly

### [GroundFlip](https://github.com/hemantrajputt/GroundFlip)
Evidence-dependence testing for MCP-grounded agents. An agent can call the right tool and still ignore what the tool returned. GroundFlip changes one field in the evidence and checks whether the agent's answer moves the way it should.

- Caught all 360 planted faults on a 72-case benchmark with no false alarms (checking only the final answer caught 20%)
- CI across three Python versions and both major MCP SDK releases
